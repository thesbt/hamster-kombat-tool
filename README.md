# 🐹 Hamster Kombat Tool

A comprehensive tool designed for managing and calculating Hamster Kombat game cards and analyzing potential earnings.

## ✨ Features

- **🔐 User Authentication**: Secure registration, login, and password reset functionality.
- **🃏 Card Management**: Browse, search, and manage game cards.
- **🛠️ Admin Dashboard**: Dedicated interface for administrators to add, update, and delete global cards.
- **📊 Usage Tracking**: Track your card levels, costs, and hourly earnings to optimize your strategy.
- **📱 Responsive Design**: User-friendly interface accessible on various devices.

## 🚀 Tech Stack

### 🖥️ Frontend
- **React**: Library for building user interfaces.
- **React Router**: For seamless navigation between pages.
- **Axios**: For making HTTP requests to the backend.
- **Bootstrap / React Bootstrap**: For responsive styling and UI components.

### 🔙 Backend
- **Node.js**: JavaScript runtime environment.
- **Express**: Web application framework for Node.js.
- **PostgreSQL**: Relational database for storing user and card data.
- **JWT (JSON Web Tokens)**: For secure user authentication.
- **Nodemailer**: For sending password reset emails.
- **Cloudinary**: For managing and optimizing image assets.
